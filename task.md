Develop a full-stack application to track books read by users.

The application should:

1. Allow the user to add a new book in a dedicated UI section.

The book must contain:

- title;
- author;
- ISBN number;
- number of pages;
- 1-5 rating.

The book must be saved in a dedicated, non in-memory database that can be deployed locally.

The application should validate the data and show appropriate error messages.

2. Allow the user to list books in a dedicated UI section.

3. Be designed with a dataset of up to 10 million records in mind.

4. Bonus: Add search functionality on the title and author fields.

Technology requirements:

- React and TypeScript are required for the frontend.
- Backend technology is your choice.
- Automated tests are a plus.

It does not need to be a production-ready application, but please comment on loose ends and possible solutions.

Please limit your time to 8 hours. If you cannot finish the app within this timeframe, submit it as-is and inform us of any incomplete features. We will assess the quality, structure, decision-making and reasoning behind your application, not only completeness.

If you used AI tools, please briefly describe how you used them and how you verified their output.
